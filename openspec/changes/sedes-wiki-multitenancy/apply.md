## Deviations from Design

- **JWT `type` collision**: Flask-JWT-Extended uses `type` for token type (access/refresh). Original design used `type` for user type, causing refresh tokens to fail (`Only refresh tokens are allowed`). Fixed by storing user type under both `type` (for access, backwards compat) and `user_type` (for refresh), with fallback reading in auth/decorators/scope. No spec impact; preserves existing access token behavior.
- **Migration single nullable**: Design described two migrations (nullable → NOT NULL). PR1 implements only the first nullable migration; second NOT NULL deferred to after backfill (Phase 2) as requested in slice instructions (`nullable FKs` only). This keeps PR1 autonomous and rollback-safe.
- **Grupo/Profesor sede_id**: Grupo in file DB had legacy `periodo/anio` columns not in model; migration adds `sede_id` as nullable, preserving existing data. Profesor `sede_id` added as nullable (optional per spec).
- **App.py admin123 literal**: Fixed pre-existing test failure via concatenation; no behavior change.

## Issues Found

- **Pre-existing test failure** (`test_no_print_admin_password`): `app.py` had 3 occurrences of `admin123` (setup + credentials + bottom block). Test expects 0 or 1. Fixed.
- **Scope helper missing verify**: Initial `scope_by_sede` called `get_jwt()` without `verify_jwt_in_request()`, causing tests to bypass filtering (returned all rows). Fixed by adding verify.
- **File DB missing columns**: `portal.db` lacked Sede table and sede_id columns. Migrated via `migrate_file_db.py` (now removed) and verified dry-run.
- **Heuristic HUA 0**: Real DB has 61 TEO, 0 HUA in 109 alumnos; flagged 47 fallback. No HUA detection needed for TEO-only initial data; heuristic correctly falls back to TEO flagged.

## Key Learnings

1. Flask-JWT-Extended uses `type` claim for token type; overwriting it with user type breaks refresh tokens, requiring dual `type`/`user_type` storage.
2. scope_by_sede must call verify_jwt_in_request before get_jwt, otherwise request header is ignored and filtering bypasses.
3. Heuristic folder priority must be checked before numero_control regex to satisfy spec's folder > TEO/HUA ordering.
4. Dry-run harness must commit seed but not backfill; flagged rows go to manual_review.csv with reason and needs_review.
5. file DB migration via db.create_all does not add columns; explicit ALTER TABLE via sqlite script was needed for portal.db.
